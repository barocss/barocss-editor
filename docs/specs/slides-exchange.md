# Slides 파일 교환과 출력

기준일: 2026-09-13. S5의 지원 형식과 제한을 기록한다.

| 형식 | 현재 지원 | 보존 범위와 제한 |
| --- | --- | --- |
| `.slides.json` | 저장·열기 | 편집 모델, 모션, 테마, 레이아웃과 참조. 외부 URL 자산의 원본 파일을 내장하지 않음 |
| 인쇄 / PDF | 파일 메뉴의 미리보기 → 브라우저 인쇄 | 보이는 장을 문서 순서로 한 장씩 출력. 장의 물리 크기, 글자, 도형과 배치 보존. 카메라·선택·노트·숨긴 장 제외 |
| `.pptx` | 미지원 | JSON 다운로드나 PDF를 PowerPoint 호환으로 표시하지 않음 |

PDF는 브라우저 인쇄 창에서 저장 대상을 선택한다. 배경 그래픽과 CSS 용지 크기를 적용한 Chromium PDF를 검사했다. 프린터의 여백·용지 맞춤 설정은 실제 출력에 영향을 줄 수 있다. 영상·오디오는 재생되지 않는다. 영상 포스터와 외부 그림·글꼴은 불러올 수 있어야 한다. 동작 링크, 객체 모션과 전환을 PDF에서 재생한다고 보장하지 않는다.

출력은 편집 DOM을 복사하지 않는다. 같은 Slides 렌더러로 문서 모델을 다시 그린다. 출력 종료 또는 취소 후 출력용 DOM을 제거한다. 현재 커서와 문서 모델은 바꾸지 않는다. 브라우저 기본 인쇄 요청도 `beforeprint`에 연결한다.

## PPTX 범위 결정

현재 1–3단계의 기본 제품 마감에서는 전용 파일과 PDF를 지원한다. S5에 정의된 **PPTX 최소 범위 결정**은 아래와 같이 기록하며, 실제 PPTX 구현은 후속 교환 작업으로 남긴다. PPTX 파일을 열 수 있는 상태가 필요하면 이 작업을 제품 출시 조건으로 올려야 한다.

첫 교환 구현은 **내보내기 우선**으로 한다. 슬라이드 크기·순서, 글자 상자, 기본 도형, 그림과 위치를 편집 가능한 객체로 내보내는 범위를 대상으로 한다. 복합 표, 컴포넌트, 자유 경로, 다중 페인트, 수식과 모션은 별도 지원표를 작성한다. 지원하지 않는 객체를 조용히 삭제하지 않으며, 그림으로 변환할 경우 변환 전 안내와 파일별 보고서를 제공한다.

가져오기는 별도 단계다. PowerPoint에서 만든 표본 파일과 내보낸 파일의 재열기로 내용·배치·글꼴 대체·손실 보고를 검증한 후에만 지원으로 표시한다. 전체 PowerPoint 충실도, 차트 데이터 및 모든 모션 왕복은 이 기본 범위에 포함하지 않는다.
