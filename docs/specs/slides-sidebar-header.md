# Slides sidebar header composition — #422

Slides navigation begins with the existing Slides/Layers/Components tabs. Its named navigation landmark, context/count row, active slide, component modes and layer controls remain unchanged. The redundant visible Navigation title row is removed.

The inspector begins with one row containing the Properties/Motion tabs and the cm/in preference. Its named Properties landmark remains. `PropertyPanel.header` is an opt-in presentation slot; when omitted, existing products keep the default title/action header. Slides supplies the compact row through this slot. Scoped Slides CSS uses existing panel and tab tokens, without changing shared token values or hiding global headers.

The tabs remain disabled during a pending property command, as before. The unit preference remains disabled only during that pending command. Property fields retain their existing busy guard, and applying/error/retry feedback remains directly below the header. Read-only protection now wraps the entire mutation body, including status and retry, with a disabled/inert fieldset; tabs and units remain outside this guard. The overlay yields ArrowLeft/ArrowRight/Home/End to sidebar and inspector tabs, so tab navigation does not nudge a selected shape. Editing commands, state, selection lifetime, unit conversion, native document format and persistence paths remain unchanged. The useful navigation count/context row is retained; further compaction and sidebar-collapse behavior are outside this iteration.
