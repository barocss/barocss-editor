# 범위

PR #250을 필수 CI 통과 후 main 08e96622로 병합했다. 후속 변경은 main 기준 별도 브랜치에서 수행한다.

- 실제 ESLint 실행 및 기존 부채를 증가시키지 않는 기준 추가.
- 로컬 사전 검사 명령과 작업 규칙 추가.
- 소스·테스트 타입 검사의 실행 실패 처리 보강. 기존 예외와 오류 한도는 유지.
- Git hook 자동 설치, 다른 PR 병합, npm publish, 서비스 배포는 포함하지 않는다.

# 완료 기준 및 검증

검사 도구 회귀 테스트와 로컬 lint·소스 타입·테스트 타입 검사 실행 결과를 기록한다. CI는 동일 검사를 다시 실행한다.

# 제한

기존 lint 오류 540개와 경고, 기존 타입 부채는 별도 정리가 필요하다. 전체 제품 인수 검사를 의미하지 않는다.

- Node 22.22.0, `pnpm preflight` 종료 0.
- 검사 도구 테스트 4개 통과.
- 실제 ESLint 2,076개 파일 검사: 기존 오류 540개, 경고 7,208개. 새 오류 없음.
- 변경한 검사 스크립트 직접 ESLint 검사: 오류 0개.
- 소스 40개 프로젝트 검사: 기존 데모 앱 예외 3개 유지.

- 별도 읽기 전용 코드 검토에서 수정이 필요한 정확성 문제 없음.
- 전체 단위 및 React 브라우저 검사는 PR CI에서 재실행한다. 이 변경은 제품 UI/편집 로직을 바꾸지 않는다.
