# 범위와 근거

CI 실행 35449695636에서 기존 단일 순회 측정이 13.19ms로 10ms 조건을 넘었다. 직전 통과 head와의 변경은 정책 문서뿐이다. 같은 66개 노드의 로컬 단일 측정은 0.07ms였다. 한 번의 cold wall-clock 측정은 초기 실행 비용과 실행기 스케줄링을 구분하지 못한다. 특정 OS 이벤트가 원인이었다고 단정하지 않는다.

기존 10ms 기준을 유지하되 정상 반복 실행의 성능을 검사한다. 준비 실행 3회, 묶음당 25회, 고정 7개 샘플의 순회당 평균 중 중앙값을 판정한다. 실패할 때까지 다시 실행하거나 통과한 표본만 고르지 않는다. 준비 실행과 모든 측정에서 전체 노드 목록 일치·중복 없음·순회 종료를 확인한다. 무한 순회는 노드 수 기준으로 중단한 뒤 실패한다.

제품 순회 구현은 변경하지 않는다. cold-start 지연의 상한을 보장하는 검사는 아니며, 전용 성능 환경의 측정을 대신하지 않는다. PR #254의 최종 검증 중 발견한 차단 항목만 함께 보강한다.
