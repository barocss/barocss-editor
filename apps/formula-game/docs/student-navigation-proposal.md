# 학생에게 익숙한 이름으로 연습 목록 만들기

검토일: 2026-09-10. 이 문서는 다음 화면 개편안이다. 현재 앱의 선택 화면과 저장된 조합은 변경하지 않았다.

## 판단

학생용 기본 경로는 학교 과목과 단원 이름을 사용한다. 지금 화면의 ‘대수·기하’는 지식을 분류하는 데는 유용하지만, 학생에게 자신의 시험 범위를 이 분류로 바꾸도록 요구한다. ‘내 교과서의 어떤 부분을 연습할까?’에 바로 답할 수 있어야 한다.

분야 이름을 학교 과목 이름으로 바꿔 붙이는 것만으로는 해결되지 않는다. ‘공통수학1’은 학교 과목이다. ‘대수’와 ‘기하’는 학문 분야 이름이며 학교 과목명으로도 사용된다. 두 분류는 목적과 범위가 다르다.

## 확인한 근거와 한계

[EBSMath 교과 목록](https://www.ebsmath.co.kr/siteMap)은 초등학교를 학년·학기, 중학교를 학년, 고등학교를 공통수학1·공통수학2·대수·미적분Ⅰ·확률과 통계 등으로 안내한다. 같은 목록은 중학교 2학년의 피타고라스 정리, 공통수학2의 직선의 방정식을 보여준다. 고등학교 과목 ‘대수’에는 지수함수와 로그함수, 삼각함수, 수열 등이 제시돼 있다.

이 목록은 익숙한 탐색 이름을 검토하는 근거로 사용한다. 서비스에 있는 콘텐츠 목록이므로, 교육과정 전체의 범위나 학교별 학기 배치를 확정하는 근거로 사용하지 않는다. 학교 과목에 실제 공식을 연결할 때는 해당 교육과정의 성취기준과 교과서 내용을 별도로 확인한다.

## 기본 화면 제안

홈: ‘내 연습 목록’과 ‘내가 본 문제’를 제공한다.

연습 목록 만들기에서는 다음 두 경로를 둔다.

1. **학교 과목으로 고르기**: 학생용 기본 경로.
2. **이름으로 찾기**: 공식이나 단원 이름을 바로 검색. 분야별 탐색도 이 경로에서 제공.

두 경로의 결과는 같은 연습 목록에 담는다. 학생이 분류 방식 자체를 배울 필요는 없다.

학교 경로의 예:

- 중학교 → 2학년 → 피타고라스 정리 → 목록에 담기.
- 고등학교 → 공통수학2 → 직선의 방정식 → 목록에 담기.
- 고등학교 → 공통수학1 → 과목 전체 또는 원하는 단원 → 목록에 담기.

예시는 탐색 설계다. 현재 앱에 위 과목 전체의 문제가 있다는 뜻은 아니다. 고등학교 과목을 특정 학년·학기에 강제로 묶지 않는다. 교육과정과 학교 편성이 다를 수 있다.

대학·전문 학습자는 학년을 강제하지 않는다. 수업명, 주제명, 공식명으로 찾게 한다. 대학의 수업 이름이 같다고 내용이 같다고 가정하지 않는다. ‘통계학개론’, ‘확률통계’, ‘응용통계’는 검색 후보가 될 수 있지만 검토 없이 같은 과목으로 합치지 않는다.

## 화면 예시

```text
연습 목록 만들기

어떤 과목을 공부하나요?
[공통수학1] [공통수학2] [다른 과목 찾기]

어디까지 연습할까요?
[과목 전체] [단원 고르기]

선택한 내용
공통수학2 · 직선의 방정식
+ 다른 단원 추가

목록 이름
[직선의 방정식 연습]  ← 자동 제안, 수정 가능

[연습 목록 저장]
```

먼저 단원을 고르게 하고, 난이도·한 번에 풀 문제 수는 ‘풀이 설정’ 안에 둔다. 기본값으로 시작할 수 있어야 한다. ‘서로 다른 항목의 조건을 함께 만족한다’ 같은 조합 규칙은 기본 화면에 노출하지 않는다.

## 쉬운 문구

| 현재                    | 제안                   | 이유                                                    |
| ----------------------- | ---------------------- | ------------------------------------------------------- |
| 내 학습 조합            | 내 연습 목록           | 저장하는 대상이 바로 보인다.                            |
| 학습 조합 만들기        | 연습 목록 만들기       | ‘조합’이라는 추상어를 줄인다.                           |
| 학습 수준               | 학교·학년              | 학교 경로에서만 사용한다. 대학·전문은 별도 경로다.      |
| 분야                    | 배우는 과목            | 단순한 이름 변경이 아니다. 학교 과목 데이터로 선택한다. |
| 주제                    | 단원                   | 학교 경로에서는 교과서에서 찾는 단위다.                 |
| 범위 1, 범위 2          | 선택한 단원            | 번호 대신 실제 선택 내용을 보여준다.                    |
| 다른 범위도 함께 익히기 | 다른 단원 추가         | 버튼을 누른 뒤 할 일을 설명한다.                        |
| 이어 익히기             | 안 푼 문제부터         | 출제 방식이 바로 보인다.                                |
| 섞어 풀기               | 섞어서 풀기            | 의미를 유지한다.                                        |
| 복습하기                | 틀린 문제·힌트 본 문제 | 현재 실제 출제 조건을 설명한다.                         |

‘대수 기초’ 같은 예시 목록도 실제 내용에 맞춰 ‘곱셈 공식 연습’처럼 이름을 붙인다. 공식의 정확한 이름은 유지하고, 필요한 경우 쉬운 설명을 덧붙인다.

## 저장 기능과의 관계

앞서 만든 여러 범위 합치기 기능은 유지한다. 학생 화면은 선택한 학교 과목·단원을 목록에 담는 방식으로 같은 결과를 만든다. 예를 들어 공통수학1의 한 단원과 공통수학2의 한 단원을 한 목록에 담을 수 있다.

기존에 저장된 분야별 조합을 학교 과목 조합으로 추정 변환하지 않는다. 기존 설정은 그대로 열고, 학교 과목 경로로 새로 만들거나 편집할 수 있게 한다. 분야별 탐색에서는 ‘대수 (분야)’처럼 학교 과목과 구별한다.

## 필요한 콘텐츠 구조

현재의 과목·분야·주제와 별도로 다음 연결을 둔다.

```text
교육과정 판본 → 학교 과목 → 단원 → 공식 연결
학문 분야 ───────────────────→ 같은 공식
```

- 교육과정 판본: 국가, 개정 연도, 근거 자료.
- 학교 과목: 표시 이름, 검색 별칭, 해당 교육과정 ID.
- 단원: 과목 ID, 표시 순서, 이름, 선택한 교과서 체계가 있다면 그 정보.
- 공식 연결: 공식 ID, 단원 ID, 근거, 검토 상태. 여러 과목에서 같은 공식을 참조할 수 있다.
- 별칭은 검색을 돕는다. 다른 교육과정의 과목을 같다고 판정하는 데 쓰지 않는다.
- 학습 수준을 ‘중등’ 하나로 저장한 기존 정보만으로 학년·학기·학교 과목을 추정하지 않는다.
- 내용이 일부만 있으면 ‘이 단원에서 현재 연습할 수 있는 공식 N개’라고 표시한다. 과목 전체를 완성했다고 표현하지 않는다.

## 다음 개편의 우선순위

1. 공통 문구를 ‘내 연습 목록’으로 통일한다.
2. 학생용 ‘학교 과목으로 고르기’ 경로를 만든다.
3. 기존 공식부터 학교 과목·단원 연결을 검토한다. 공개할 수 있는 범위만 표시한다.
4. 공식·단원 이름 검색과 별칭을 추가한다.
5. 기존 분야별 조합은 직접 찾기 경로로 유지한다.

학생 검증에서는 ‘이번 시험에서 피타고라스 정리를 연습하려 한다’ 같은 과제를 준다. 선택을 마칠 때까지 걸린 시간, 되돌아간 횟수, 선택한 목록의 실제 범위를 이해했는지를 확인한다. 학교 과목명 우선이라는 판단을 실제 학생 사용 결과로 확인한다.
