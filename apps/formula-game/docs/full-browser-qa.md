## 수정한 문제

1. 단원 검색 결과가 없을 때 전체 선택만 남아 상태를 알 수 없었다. `PresetEditor.tsx`에 검색 결과 없음 안내를 넣었다. 검색어 앞뒤 공백도 무시한다. 브라우저에서 결과 없음과 검색 복원을 다시 확인했다.
2. 유도 마지막 줄에도 ‘다음 줄을 열 때 저장’이라고 표시됐다. `DerivationPlayer.tsx`에서 마지막 줄은 ‘완성한 유도를 볼 때 저장’으로 구분했다. 마지막 줄까지 다시 풀어 문구와 완료 버튼이 일치하는지 확인했다.

## 검증 한계

- 토스·샌드박스의 실제 네이티브 Storage, 앱 종료·재실행, 기기 키보드·터치 선택·안전 영역은 실기기 검증이 필요하다. 브라우저 드래그가 모바일 터치 핸들의 검증을 대신하지 않는다.
- 저장소 용량 초과, 네이티브 저장 실패, 이전 도중 오류, 손상된 기록은 이 브라우저에서 강제로 만들지 않았다. 해당 저장 계층은 비동기 테스트 저장소를 사용하는 자동 테스트에서 검사한다.
- 외부 참고자료 링크는 화면의 링크와 목적지 표시를 확인했다. 각 외부 사이트의 가용성을 모두 확인한 것은 아니다.
- 이전 버전 문제와 보관된 해설 스냅샷의 처리도 자동 테스트 범위다.
