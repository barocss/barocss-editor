# 한 줄씩 유도하기

2026-09-10 구현. 홈에서 별도 연습으로 연다.

## 학습 흐름

1. 그림과 조건을 읽는다. 아직 완성 공식을 보여주지 않는다.
2. 현재 줄의 빈칸을 기존 math-editor로 입력한다. 제곱 등 구조 추천을 그대로 쓴다.
3. 오답이면 현재 줄을 유지한다. 입력을 고치거나 힌트를 볼 수 있다.
4. 정답이면 그 줄의 이유를 읽는다. ‘다음 줄 열기’를 누르면 저장하고 다음 줄을 표시한다.
5. 완성한 줄은 위에 남는다. 아직 풀지 않은 줄은 렌더링하지 않는다.
6. 마지막 줄까지 완료하면 전체 풀이와 공식 해설을 보여준다.
7. 홈에서 다시 들어오면 저장한 다음 줄 또는 완료 화면을 연다. 처음부터 다시 풀 수도 있다.

## 첫 콘텐츠: 피타고라스 정리

양수 a, b를 직각변으로 하고 c를 빗변으로 하는 합동 직각삼각형 네 개를 사용한다. 큰 정사각형의 한 변은 a+b다. 가운데 도형은 네 변이 c이고, 각이 90°인 정사각형이다. 각의 설명에는 피타고라스 정리를 사용하지 않는다.

- 큰 정사각형의 넓이 전개: (a+b)² = a²+2ab+b²
- 삼각형 네 개의 넓이: 4×ab/2 = 2ab
- 가운데 넓이: c² = (a+b)²−2ab
- 정리: c² = a²+2ab+b²−2ab = a²+b²

[UBC 넓이 증명 자료](https://personal.math.ubc.ca/~cass/courses/m308-7b/pythagorasdissection.html)를 바탕으로 만든 학습용 구성이다. 피타고라스 개인이 실제로 사용한 증명법이라고 주장하지 않는다.

## 데이터와 제한

`src/derivations.ts`의 정의는 ID, 개정 번호, 원본 공식 ID, 단계별 입력·힌트·설명·허용 정답을 가진다. 원본 공식과 입력 프로필을 참조한다. 단계는 일반 빈칸 문제 은행과 별개다. 따라서 4단계를 기존 21문제에 더하지 않는다.

진행은 사용자 ID, 유도 ID와 개정 번호, 원본 공식 개정 번호별로 저장한다. 저장 답안을 순서대로 다시 검사하고 유효한 앞부분만 복원한다. 오답으로 다음 단계에 갈 수 없다. 저장 실패를 화면에서 알린다. 아직 제출하지 않은 입력과 힌트 사용 내역은 복원하지 않는다.

현재 채점은 제한된 정답 목록이다. 임의의 동치식을 모두 판단하지 않는다. 첫 단계는 전개된 식을 요구한다. 뺄셈 뒤의 복합 답안은 괄호로 표시해 식의 뜻을 보존한다.

현재는 넓이 증명 한 가지를 제공한다. 분기형 증명, 자유로운 여러 줄 증명, 보관함 통합 목록, 서버 동기화는 후속 범위다. 새 유도를 추가할 때 그림·조건, 단계 간 수학적 연결, 입력 가능한 정답, 오답 정지와 저장 복원을 함께 확인한다.
