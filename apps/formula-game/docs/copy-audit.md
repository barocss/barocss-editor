## 해설 데이터

옴의 법칙, 운동 에너지, 두 값의 산술평균은 해설 도입부와 첫 단계에 같은 문장이 반복된다. 도입부에서 개념을 설명하고 각 단계에는 실제 식의 전개만 두는 방식으로 정리한다. 위치는 `src/database/data/packs/foundations-physics.ts`와 `foundations-statistics.ts`다.

변수의 뜻, 단위, 성립 조건, 증명의 이유는 학습 내용이므로 삭제하지 않는다. 예를 들어 ‘b는 밑변, h는 그 밑변에 수직인 높이’와 ‘옴(Ω)’은 문제 풀이에 필요하다. 피타고라스가 직접 사용한 증명인지 단정할 수 없다는 설명도 사실 관계를 전달하므로 유지한다.

## 적용 원칙

- 화면 제목은 목적을, 버튼은 동작을 표시한다.
- 숫자와 상태로 전달할 수 있는 내용은 문장으로 반복하지 않는다.
- ‘모아드려요’, ‘함께 익혀요’, ‘스스로 떠올려 보세요’ 같은 서비스의 권유는 줄인다.
- 빈 화면, 오류, 입력 범위처럼 판단에 필요한 안내는 해당 상황에만 표시한다.
- 모든 문장을 명사형으로 바꾸지 않는다. 문제와 해설은 읽기 쉬운 문장으로 쓴다.

추천 적용 순서: 홈·공통 헤더 → 학습 설정 → 결과·보관함 → 입력 안내 → 해설 중복.

## 적용 기록

- 홈, 학습 설정, 결과, 보관함, 입력기, 유도, 로딩·저장 오류 안내에 반영했다.
- 입력 대상 안내, 분자·분모 선택, 저장 시점과 오류 재시도 버튼을 유지했다.
- 옴의 법칙·운동 에너지·산술평균 해설의 반복 문장을 정리하고 JSON 내보내기를 갱신했다.
- 문구 편집이므로 공식·문제 revision과 학습 기록 키는 유지했다. 콘텐츠 묶음과 DB 스냅샷 revision만 올렸다. 기존 보관함의 해설 스냅샷은 당시 내용을 보존하므로 과거 문구가 남을 수 있다.

검증: 기존 자동 테스트 46개, 린트, 웹·앱인토스 빌드 통과. localhost:5187에서 홈 배치, 학교·분야별 학습 설정, 보관함 하단 저장 안내, 문제 입력 안내를 확인했다. 콘솔 오류는 없었다.
