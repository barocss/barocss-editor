# 키패드 위 맞춤 추천

미니앱은 키패드 바로 위에 추천 버튼을 표시한다. 입력할 때나 드래그할 때 큰 드롭다운을 열지 않는다.

## 역할

- math-editor: 추천 생성, 선택 영역 관리, 수식 구조 변환, 실행 취소.
- 미니앱: 문제의 InputProfile에서 허용한 구조만 버튼으로 표시한다.
- 선택하지 않았을 때는 현재 입력에 대한 제곱·분수·루트 중 허용한 항목을 표시한다.
- 선택 영역이 있으면 같은 자리에 ‘분자로 넣기’, ‘분모로 넣기’ 등 허용한 변환을 표시한다. 부분 선택도 그대로 보존한다.
- 정답은 추천 함수에 전달하지 않는다. 작성자가 설정한 입력 범위를 사용한다.

## math-editor DOM 설정

`mountMathEditor`의 `suggestionMenu: false`는 내장 추천·선택 드롭다운과 그 메뉴의 키보드 동작을 끈다. 기본값은 기존 동작이다. 앱은 세션 구독과 `findStateSuggestions`, `acceptSuggestion`, `wrapRange`로 원하는 위치에 UI를 구성한다.

내장 메뉴를 사용하는 다른 앱은 `filterSuggestions(candidates, query)`와 `selectionKinds`로 표시 항목을 제한할 수 있다. 이 미니앱은 자체 추천 영역을 사용하므로 두 설정이 필요하지 않다.

## 문제별 범위

- 직사각형·삼각형 넓이, 옴의 법칙, 산술평균·표준점수: 분수.
- 원의 방정식: 제곱.
- 원점까지의 거리: 제곱·루트.
- 운동 에너지: 제곱·분수.

## 브라우저 검증 (2026-09-10)

1. 키패드로 bh 입력. 드롭다운이 나타나지 않는다.
2. 실제 마우스로 bh 전체를 드래그. 키패드 위에 분자·분모 버튼이 표시된다.
3. ‘분모로 넣기’ 후 분자에 1 입력 → 1/(bh).
4. 입력과 변환을 실행 취소 → 선택한 bh와 두 버튼이 복원된다.
5. ‘분자로 넣기’ 후 분모에 2 입력 → bh/2.
6. 각 단계에서 수식의 변경이 문제의 빈칸에도 반영된다. 브라우저 오류는 없다.
