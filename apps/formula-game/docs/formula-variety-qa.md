# 다양한 공식 화면 검증 — 2026-09-10

검증 대상: localhost:5187의 현재 빌드. 별도 Chrome 탭에서 실제 키패드와 추천 버튼, 마우스 드래그를 사용했다. 앱의 내부 상태나 정답을 주입하지 않았다.

## 추가 상호작용

- 루트 안에 x²+y²를 입력했다. 두 제곱과 덧셈이 루트 안에 유지됐다. 이는 입력 구조 검사이며 해당 문제의 정답으로 제출하지 않았다.
- 운동 에너지에서 mv 입력 후 제곱을 눌러 v에만 제곱이 붙는 것을 확인했다.
- 평균 문제에서 a+b 전체를 마우스로 드래그했다. 연산자를 포함한 선택이 표시됐다.
- ‘분모로 넣기’ 후 1을 입력해 1/(a+b)를 만들었다. 두 번 실행 취소해 a+b를 복원했다.
- a+b를 다시 선택한 뒤 ‘분자로 넣기’와 2 입력으로 (a+b)/2를 만들었다. 실제 채점에서 정답으로 처리됐다.
- 일반 문제 입력 중 큰 추천 드롭다운이 나타나지 않았다.
- 유도 첫 단계에서 a²+b²만 제출하면 다음 줄이 열리지 않고 오답 안내가 나왔다.
- 힌트를 연 뒤 기존 식에 +2ab를 추가하면 정답이 됐다.
- 첫 단계를 완료하고 다음 줄을 연 뒤 새로고침했다. 유도 화면에 다시 진입하자 1/4 완료 상태와 두 번째 단계가 복원됐다.
- 마지막 단계의 ‘완성한 유도 보기’를 눌러 4/4 완료를 확인했다.
- 브라우저 콘솔 오류: 0건.

## 남은 범위와 개선점

- 전체 37개 일반 문제 중 16개를 검증했다. 나머지 문제와 토스 앱 내 실기기 동작은 이번 검증 범위에 포함하지 않았다.
- 피타고라스 유도는 아직 4단계 모두 algebra-ab 입력 설정을 공유한다. 기능은 동작하지만 불필요한 분수·루트 추천을 단계별로 줄일 수 있다.
- a+b처럼 여러 토큰을 가로지른 선택은 실행 취소 시 수식은 복원되지만 선택 강조는 복원되지 않았다. 재선택 후 변환은 정상이다.
