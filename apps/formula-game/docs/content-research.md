# 공식 한 칸: 문제 구성과 다음 연구

조사일: 2026-09-10. 아래 권고는 학습 자료를 참고한 제품 설계 판단이다. 앱 자체의 학습 효과를 검증한 결과는 아니다.

## 이번에 구현한 범위

대수 공식 10개와 연습 20문제. 과목·분야·학습 수준·주제와 문제 난이도를 분리했다. 한 번에 5·10·20문제를 선택한다. 문제의 계수·항·인수를 빈칸으로 만들며 결과값 계산으로 바꾸지 않는다. 게임 단계는 앱 내부 난이도이고, 특정 학년의 교육과정 전체를 의미하지 않는다.

| 단계 | 범위                                            | 입력 난이도                    |
| ---- | ----------------------------------------------- | ------------------------------ |
| 입문 | 분배법칙, 공통인수, 제곱 공식의 계수, 제곱의 차 | 짧은 항과 계수, 제곱 입력 시작 |
| 기본 | 합과 차의 제곱, 제곱의 차, 공식 역방향          | 두 항, 제곱 서제스천           |
| 응용 | 계수가 있는 곱셈·인수분해, 두 공식의 차, 상수항 | 계수와 부호 구별               |
| 도전 | 세제곱의 합·차, 네제곱의 차, 공식 조합          | 여러 항을 입력                 |

모든 문제는 모든 실수 a, b에서 성립한다. 공식에는 ID, 개정 번호, 조건, 변수, 출처, 주제와 학습 수준을 기록한다. 문제에는 공식 ID, 난이도, 빈칸, 허용 답안, 입력 프로필, 힌트와 해설을 기록한다. tests/polynomial.mjs의 독립된 정수 계수 다항식 전개기로 모든 허용 답안의 항등식을 확인한다. 임의 숫자 몇 개를 대입하는 방식이 아니다.

문제별 풀이 횟수·정오답·힌트 기록을 기기 내에 저장한다. 새 공식 추가 시 기존 문제 기록은 유지한다. 개정된 문제는 별도 기록을 쓴다. 힌트를 확인한 문제 수를 표시한다. 힌트 없이 다시 떠올리기를 권하지만 이를 숙달 판정으로 사용하지 않는다.

## 다음 추가 우선순위

### 1. 현재 공식의 다른 빈칸 — 우선

20문제를 60개 안팎의 변형으로 확장한다. 같은 공식을 연속으로 제시하지 않고, formulaId와 문제 id를 구분해 관리한다. 계수 → 항 → 인수 → 반대 방향 순으로 복잡도를 높인다. 현재 콘텐츠 묶음 구조와 미풀이 우선·섞기·복습 출제를 구현했다. 날짜별 출제와 간격 반복 알고리즘은 아직 없다.

추가 조건: 숫자만 바뀐 중복 콘텐츠를 늘리기보다 실제로 다른 부분을 회상하도록 한다. 한 문제에서 방금 본 답을 다음 문제에 그대로 쓰는 흐름을 피한다.

### 2. 제곱근 — 입력 경험 검증 후

후보: 제곱근의 곱, 제곱근의 몫, 제곱의 제곱근, 간단한 유리화.

필수 조건:

- sqrt(a²)=|a|. 조건 없는 답 a를 정답으로 등록하지 않는다.
- sqrt(a)sqrt(b)=sqrt(ab)는 실수 범위에서 a≥0, b≥0를 명시한다.
- sqrt(a)/sqrt(b)=sqrt(a/b)는 a≥0, b>0를 명시한다.
- 절댓값 구조와 분수의 분모 이동을 먼저 구현·검증한다.
- 현재 다항식 허용 목록만으로 근호 동치를 판정하지 않는다.

### 3. 이차방정식 — 긴 수식 조작을 확인한 뒤

후보: 근의 공식의 2a, 판별식 b²−4ac, 근과 계수의 관계.

필수 조건: a≠0. 실수 근을 다룬다면 판별식 조건을 표시한다. c, x, ±, 분수, 루트가 필요하므로 문자 키 선택과 안전한 괄호 조작을 준비한다. 전체 근의 공식 입력보다 분모 또는 판별식의 한 항부터 시작한다.

### 4. 지수법칙 보강 — 변수 지수 입력이 준비되면

후보: a^m a^n=a^(m+n), (a^m)^n=a^(mn), 지수의 뺄셈.

자연수 지수와 정수 지수를 구분한다. 나눗셈·음수 지수에서는 a≠0 조건이 필요하다. 현재 추천은 제곱 고정이므로 일반 지수 입력이 먼저 필요하다.

### 보류

삼각함수, 로그, 미분·적분: 선수 지식, 함수 입력, 정의역과 조건이 복잡해진다. 초기 사용자가 중등 기본 문제를 편하게 입력하는지 확인한 뒤 확장한다.

## 제품 실험 후보

- 오답 즉시 재입력에 더해, 다른 문제 뒤 또는 다음 방문에 다른 빈칸으로 다시 제시한다.
- 첫 시도 정답, 힌트 사용, 빈칸 입력 시간, 지우기·되돌리기 횟수를 구분한다. 자동 수집은 아직 없다. 동의와 데이터 범위를 정한 후 도입한다.
- 정답을 알고도 입력을 포기하는 사례를 관찰한다. 학습 난이도와 편집기 조작 난이도를 분리한다.
- 현재 허용 답안에 없는 동치식을 오답으로 처리할 수 있다. 출시 전에는 제한된 다항식의 정확한 동치 판정과 '전개/인수분해 형태' 판정을 분리하는 것을 검토한다.
- 문제 검수에서는 원식·완성식, 조건, 오개념 예시, 허용 답, 입력 경로를 함께 확인한다.

## 후속 조사 기록 원칙

공식 학습 자료와 원 연구를 우선한다. 새 출처, 변경된 판단, 구현의 선행 조건을 남긴다. 확인한 내용이 바뀌지 않으면 동일한 권고를 반복하지 않는다. 과장된 학습 효과 수치나 검증하지 않은 학년 배치를 제품에 표시하지 않는다.

## 구조 확장 이후 연구 방향

[콘텐츠 작성 지침](content-authoring.md)을 따른다. 다음 연구는 대수에만 한정하지 않는다. 초등 도형·비례, 중고등 수학, 물리 역학, 화학의 양적 관계, 통계, 전기 회로에서 대표 공식을 후보로 정리한다. 각 후보의 적용 조건, 학습 수준 근거, 모바일 입력 가능성, 채점 방식을 함께 확인한다. 출처를 확인하지 않은 공식은 공개 콘텐츠에 넣지 않는다.

## 2026-09-10 실제 공식 추가

8개 공식을 3개 독립 콘텐츠 팩으로 추가했다. 공식마다 2문제를 연결했다. 출처는 각 공식의 `sources`에도 저장한다.

- 직사각형·삼각형 넓이: [OpenStax Prealgebra 9.4](https://openstax.org/books/prealgebra-2e/pages/9-4-use-properties-of-rectangles-triangles-and-trapezoids). 삼각형 높이는 선택한 밑변에 수직이다.
- 원점까지의 거리·원점 중심 원: [OpenStax Intermediate Algebra 11.1](https://openstax.org/books/intermediate-algebra-2e/pages/11-1-distance-and-midpoint-formulas-circles). 일반 공식 중 원점을 기준으로 하는 경우를 먼저 제공한다.
- 옴의 법칙: [OpenStax University Physics 9.4](https://openstax.org/books/university-physics-volume-2/pages/9-4-ohms-law). 일정한 온도에서 저항이 일정한 도체로 조건을 제한한다.
- 운동 에너지: [OpenStax University Physics 7.2](https://openstax.org/books/university-physics-volume-1/pages/7-2-kinetic-energy). 비상대론적 병진 운동을 다룬다.
- 두 값의 산술평균: [NIST Measures of Location](https://www.itl.nist.gov/div898/handbook/eda/section3/eda351.htm). 같은 가중치를 갖는 두 관측값만 다룬다.
- 표준점수: [OpenStax Introductory Statistics 6.1](https://openstax.org/books/introductory-statistics/pages/6-1-the-standard-normal-distribution). 표준편차는 양수다. 표준화 연산 자체에는 정규분포 가정이 필요하지 않음을 설명한다.
