# 실제 공식 화면 검증 — 2026-09-10

현재 제공량: 공식 19개, 문제 37개. 이번 추가량: 공식 8개, 문제 16개. 각 공식에 성립 조건, 기호 설명, 원리 해설과 출처를 연결했다. 전체 교과과정 수록을 뜻하지 않는다.

## 브라우저 검증

localhost:5187의 빌드 결과에서 학습 선택 → 저장 → 문제 시작 → 키패드 입력 → 채점 → 결과를 직접 실행했다. 도형 4문제는 Codex 내장 브라우저, 나머지 12문제는 별도 Chrome 탭에서 확인했다.

| 학습 | 추가 공식 | 직접 입력한 답안 | 결과 |
|---|---|---|---|
| 초등 도형 | 직사각형·삼각형 넓이 | ab, bh, A/a, bh/2 | 4/4 정답 |
| 공통수학2 도형의 방정식 | 원점까지의 거리·원점 중심 원 | y², r², x², r²−x² | 4/4 정답 |
| 물리 회로와 운동 | 옴의 법칙·운동 에너지 | IR, v², V/R, mv² | 4/4 정답 |
| 대학 응용통계 | 두 값의 산술평균·표준점수 | a+b, x−μ, (a+b)/2, (x−μ)/σ | 4/4 정답 |

- 제곱은 키패드 문자 입력 뒤 제곱 추천 버튼으로 입력했다.
- 분수는 빈 편집기에서 분수 버튼을 누른 뒤 분자 → 다음 칸 → 분모 순서로 입력했다.
- 직사각형 넓이에 a만 입력하면 오답과 정답 ab가 표시됐다.
- 표준점수의 마지막 답안과 원리 해설을 본 문제 목록에서 열었다.
- 같은 Chrome에서 앱을 새로 열었을 때 저장한 학습 3개와 본 문제 12개가 유지됐다.
- 삼각형 조건이 큰 h1(24px), 공통 입력 안내가 작은 문구(12px)로 표시되는 것을 화면에서 확인했다. 강제 줄바꿈을 제거했다.

## 자동 검증

34개 테스트 통과. 새 공식의 허용 답안, 편집기의 제곱·그리스 문자 직렬화, 잘못된 부호·분모·괄호 범위 거부를 검사한다. 기존 분류, 기록, 유도 연습 테스트도 포함한다.

## 검증 범위

브라우저 프로토타입 검증이다. 토스 앱 안에서의 실기기 검증은 별도다. 채점은 등록한 동치 답안 목록을 기준으로 하며 범용 기호 계산기는 아니다. 기록은 현재 기기의 사용자 저장소에 보관한다.
