# 공식 한 칸 — 앱인토스 프로토타입

공식의 빈칸에 수식을 입력하는 모바일 미니앱입니다. 현재 공식 19개와 연습 37문제, 피타고라스 정리의 4단계 유도 연습을 제공합니다.

## 내 연습 목록

홈 → 학교 과목 → 단원 → 연습 목록 저장 → 문제 → 결과 순서입니다. 현재 중2·중3 수학, 공통수학1·2의 일부 단원을 선택할 수 있습니다. 공통수학2에서는 원점까지의 거리와 원의 방정식 4문제를 제공합니다. 개수는 현재 제공 분량이며 과목 전체 수록을 뜻하지 않습니다.

여러 과목의 단원을 함께 담을 수 있습니다. ‘분야로 직접 찾기’에서는 기존 과목·학습 수준·분야·주제 조건을 사용합니다. 기존 목록은 그대로 편집할 수 있습니다. 목록은 편집·복제·삭제·삭제 되돌리기를 지원합니다. 출제 수는 5·10·20문제이며, 콘텐츠 수와 별개입니다.

[상세 화면 흐름](docs/app-flow.md)에 과목 연결, 저장 규칙, 로딩 화면을 설명했습니다. 단원과 공식의 연결은 `src/curriculum.ts`에서 관리합니다. 새 공식과 연결 데이터를 추가하면 해당 목록에 반영됩니다.

## 한 줄씩 유도하기

홈에서 피타고라스 정리의 넓이 증명을 시작합니다. 현재 줄을 수식 편집기로 완성하고 확인합니다. 맞히면 이유를 읽고 다음 줄을 엽니다. 틀리면 같은 줄에서 다시 풉니다. 다음 줄을 열 때 진행을 기기에 저장합니다. 완료한 풀이와 해설은 다시 볼 수 있습니다. [단계와 저장 설계](docs/derivation-play.md)를 참고하세요.

## 내가 본 문제와 해설

홈의 ‘내가 본 문제’에서 이전 문제를 검색하고 미풀이·오답·정답으로 걸러 볼 수 있습니다. 정답을 제출하기 전에도 기록합니다. 문제 상세에는 마지막 답안, 정답·문제 해설, 공식의 조건·변수·유도 과정·참고 자료가 있습니다. 현재 공개 버전으로 다시 풀 수 있습니다.

피타고라스 해설에는 변의 길이를 바꿀 수 있는 넓이 그림과 역사 자료를 넣었습니다. 역사적 인물의 실제 증명법과 학습용 증명을 구분합니다.

기록은 이 브라우저의 익명 사용자 ID별로 저장합니다. 실제 로그인이나 기기 간 동기화는 없습니다. 같은 브라우저를 함께 쓰면 같은 기록을 봅니다. 문제와 해설을 함께 저장하므로 나중에 콘텐츠가 수정돼도 당시 본 내용을 읽을 수 있습니다. 저장 차단·용량 부족 시 안내합니다. 브라우저 데이터를 지우면 기록도 사라집니다.

## 실행

Node.js 24 이상을 사용합니다. 이 폴더는 저장소의 pnpm 의존성과 충돌하지 않도록 독립 npm 설치를 사용합니다.

```sh
cd apps/formula-game
npm ci --workspaces=false
npm run dev
```

브라우저: http://localhost:5186

공식 SDK 3.4.0, 공식 devtools 3.2.0, React 18, TDS를 사용합니다. 설치 시 devtools 3.4.0은 레지스트리에 없었으므로 배포된 3.2.0을 연결했습니다. 실제 설치 버전은 package-lock.json에 고정합니다. 개발 도구는 개발 모드에만 주입됩니다.

기존 math-editor의 `/core`, `/dom`, CSS를 Vite alias로 참조합니다. npm에 배포된 다른 버전을 쓰지 않습니다. 이 앱을 다른 저장소로 옮기려면 alias와 TypeScript paths를 바꾸고 math-editor 의존성을 설치해야 합니다.

## 확인과 빌드

```sh
npm test
npm run type-check
npm run lint
npm run build
```

`build`는 콘텐츠 ID·참조·버전·채점 방식 등을 검증한 뒤 웹 파일을 빌드하고 공식 CLI로 `formula-game.ait`를 생성합니다. SDK 3.x에서는 `apps-in-toss.config.ts`를 사용합니다. 이전 `granite.config.ts`는 사용하지 않습니다.

## 토스 앱에서 테스트

1. 앱인토스 콘솔에서 게임 미니앱을 등록합니다.
2. `apps-in-toss.config.ts`의 `appName: 'formula-game'`을 실제 등록한 appName으로 바꿉니다. 현재 값은 프로토타입 식별자입니다.
3. 앱 이름, 로고, 게임 등급 등 콘솔의 필요한 정보를 등록합니다.
4. `npm run build` 후 생성된 `.ait` 파일을 콘솔에 업로드합니다.
5. 콘솔이 제공하는 테스트 링크 또는 QR로 토스 앱에서 실행합니다.
6. iOS·Android에서 입력, 안전 영역, 닫기, 화면 복귀를 확인합니다.

이 작업에서는 콘솔 등록·업로드·심사 요청을 하지 않았습니다. 실제 토스 앱에서의 실행 검증도 아직 하지 않았습니다. 브라우저 TDS provider와 토스 앱 TDS provider는 실행 환경에 따라 선택됩니다. 실제 게임 화면의 토스 공통 내비게이션은 콘솔 설정과 함께 확인해야 합니다.

## 범위

- 문제 수식은 고정하고 답안 편집기만 수정할 수 있습니다.
- 구조 추천은 math-editor의 findStateSuggestions와 acceptSuggestion을 사용합니다. 입력한 항을 제곱·분수·루트로 바꿉니다. 제곱은 지수 2 입력과 커서 이동을 하나의 되돌리기 작업으로 처리합니다.
- 분모 등을 입력한 뒤 다음 칸 버튼으로 이동할 수 있습니다. 정답이나 완성된 공식은 추천하지 않습니다.
- 정답은 문제별 허용 목록과 제한된 정규화로 판정합니다. 임의의 동치 수식 전체를 판정하지 않습니다.
- 기본 팝업 추천 메뉴는 숨기고 게임용 구조 후보를 입력창 아래 한 줄로 표시합니다. 소프트 키보드는 숨기며 물리 키보드 입력은 가능합니다.
- 문제별 정오답·힌트·풀이 횟수는 이 기기의 브라우저 저장소에만 저장합니다. 로그인, 서버, 광고, 결제, 리더보드는 포함하지 않습니다.
- 한 번에 풀 문제 수는 콘텐츠 총량과 별개입니다. 조건에 맞는 문제가 부족하면 실제 수를 표시합니다. 이어 익히기는 안 푼 문제와 적게 푼 문제를 우선합니다. 한 라운드에서 공식 종류를 먼저 고르게 배치합니다.
- 새 기록은 v3 저장소에 문제 ID·문제 개정·공식 개정별로 저장합니다. v1·v2 점수는 지우지 않습니다. 과거 합계 점수만으로 개별 문제의 정오답을 알 수 없어 새 기록으로 변환하지 않습니다.
- 다른 과목은 분류만 준비했습니다. 실제로 공개한 문제만 선택하고 실행할 수 있습니다.
- [콘텐츠 추가 구조와 절차](docs/content-authoring.md)를 따라 공식과 문제를 추가합니다.
- [문제 구성과 다음 연구](docs/content-research.md)에 출처, 확장 순서와 선행 조건을 정리했습니다.

공식 자료: https://github.com/toss/create-ait-app 및 설치한 SDK 3.4.0의 설정 타입과 CLI 안내를 기준으로 구성했습니다.

## 분류 목록

과목 19개, 학습 수준 22개, 분야 75개를 독립된 데이터로 관리합니다. 부모 분류와 검색 별칭을 지원합니다. [전체 목록과 문제 연결표](docs/taxonomy-catalog.md), [등록 규칙](docs/taxonomy-design.md)을 참고하세요. 등록된 모든 분류에 문제가 있는 것은 아닙니다.

화면의 저장 단위는 ‘내 학습’입니다. 학습 내용 보기, 학습 편집, 복제, 삭제를 지원합니다.

## 파일 DB

서버 없이 `src/database/data/`의 TypeScript 데이터를 읽습니다. 전체 데이터는 `npm run db:export`로 `data/formula-game.json`에 내보낼 수 있습니다. 원본 수정, 데이터 연결과 서버 전환 범위는 [정적 DB 안내](docs/static-database.md)를 참고하세요.
