# Package map

The current package map is the [generated package catalogue](/packages). It reads the package names, versions, and public entry points from package manifests and uses the English README of each package.

Packages are grouped into products, shared Office UI, shared Office behavior, editor foundations, collaboration, and tools. See [package boundaries](../guides/package-boundaries.md) for ownership rules.

This URL remains available for older links. Do not maintain another hand-written package/version list here.
