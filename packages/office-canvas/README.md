# @barocss/office-canvas

What two products place things with: boxes, dragging, arranging, connectors, components and variables on a canvas

Install with `pnpm add @barocss/office-canvas`.

This package provides ES modules and TypeScript declarations.

See the [Wonffice repository](https://github.com/barocss/barocss-editor) for source code and documentation.
