# Drop Behavior Specification — Superseded

The former drop behavior labels, registry, and schema hints have been removed. They are not supported APIs. The old examples did not define the validated editing plans required by the current design.

- [Removal and migration](./drop-behavior-architecture.md)
- [Current editing policy specification](../../../docs/specs/schema-editing-policy.md)
- [Custom schema and editing guide](../../../docs/schema-editing-guide.md)

DND input integration remains tracked by [#265](https://github.com/barocss/barocss-editor/issues/265). The current fragment policy API does not imply that drag handlers already use it.
