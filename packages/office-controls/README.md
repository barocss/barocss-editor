# @barocss/office-controls

What a control is, and how it reads a selection — the vocabulary every product's toolbar is declared in

Install with `pnpm add @barocss/office-controls`.

This package provides ES modules and TypeScript declarations.

See the [Wonffice repository](https://github.com/barocss/barocss-editor) for source code and documentation.
