# @barocss/office-note

One written thing: the schema, the kit and the editing session a body of prose needs — a CMS field, and a note on its own

Install with `pnpm add @barocss/office-note`.

This package provides ES modules and TypeScript declarations.

See the [Wonffice repository](https://github.com/barocss/barocss-editor) for source code and documentation.
