# Note document editing and current authority

Permitted writers edit continuously. There is no writing/reading toggle or saved mode preference. Text selection owns formatting tools. An explicit block action owns its block menu and retires the text toolbar until dismissal. The Note session, model, view, layout and undo history remain mounted.

The local workspace supplies current write authority for non-trashed pages. The authenticated host supplies current role, busy, pending-request and protected-copy constraints. Viewers and protected states remove mutation overlays and make the existing content layer non-editable. Note refuses native input, paste, drop, cut and mutation shortcuts at its boundary. Text selection, copy, links, disclosures and find remain available. The server host routes Cmd/Ctrl+F outside the editor to a request scoped to the current document generation.

Snapshot delivery waits for pending DOM input and delivers nested bodies deepest first. Active composition, failed child delivery and retired session/root ownership refuse delivery. A new authenticated save includes delivered nested content. An immutable knownAttempt retry skips mutable draft delivery and reuses the exact stored request bytes.

A save token serializes its current session. Async receipt, clipboard and status results check the captured client, session and generation before changing the current UI. Confirmed durable records can survive a retired document generation on the same client, but an inactive account client cannot rewrite private pending storage after retirement.

Focused mounted tests verify native equality, the same view, meaningful undo/redo, current authority changes, input refusal, copy allowance, composition refusal and queued delivery refusal. Actual desktop and authenticated persistence evidence belongs to the exact candidate. Synthetic composition tests verify event guards only. Physical Korean IME remains unverified until an operator runs that scenario. This Note change does not establish four-product or alpha release readiness.
